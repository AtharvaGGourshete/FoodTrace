# FoodTrace

Blockchain-Based Food Supply Chain Traceability System.

## Project Structure

- `frontend/` — React + Vite frontend
- `backend/` — Node.js + Express backend
- `blockchain/` — Solidity smart contracts + Hardhat

## Core Architecture

React
↓
ethers.js
↓
MetaMask
↓
Ganache
↓
FoodTrace Solidity Smart Contract

## Supporting Architecture

React
↓
Node.js + Express
↓
PostgreSQL

## Core Features

- Role-based access
- Product registration
- Batch creation
- Batch tracking
- Ownership transfer
- Shipment/receiving
- Supply-chain history
- Batch recall
- QR-based verification
